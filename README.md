# Holdwise – Investment Portfolio Tracker

Holdwise is a Django web application for tracking investment portfolios. Users create portfolios, add holdings by ticker symbol, and see live prices, current value and profit/loss for each position, powered by data from Yahoo Finance via `yfinance`.

## Status

In development – Django Basics Regular Exam project @ SoftUni.

## Tech stack

- Python 3.13
- Django 6.1
- SQLite
- yfinance
- Bootstrap
